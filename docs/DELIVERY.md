# 交付说明

更新日期：2026-10-21。此文档记录当前源码的真实状态，便于查看、运行和继续验收。

## 已完成内容

- 从空目录搭建 React 19 + TypeScript + Vite 7 前端项目，使用 React Router 管理商品列表、详情、购物车及未找到页面。
- 完成中文界面、八件模拟家居商品、原创内联 SVG 商品插画与响应式样式。商品价格以美元展示。
- 商品列表支持关键词搜索、分类筛选、精选及价格排序，并提供无结果和清除筛选状态。
- 商品详情支持数量选择和加入购物车。购物车支持合并同款、修改数量、移除商品、金额汇总与浏览器本地保存。
- 对不存在的商品链接和无效购物车数据提供代码层面的回退逻辑。页面含跳转主内容入口、控件标签、焦点样式和减少动态效果适配。
- 已明确标注这是演示商店，不支持结账或付款。

## 已知问题和未验证范围

- 还没有在准确的 375 px、768 px、1440 px 视口逐页验收；目前只在约 427 px 的浏览器窗口做了可见检查。
- 价格排序已实现，但尚未在浏览器中逐项核对排序顺序。
- `localStorage` 损坏数据的回退逻辑已编写，尚未做手工注入验证。完整键盘主流程也尚未走完。
- 示例商品的名称、规格与价格都是模拟内容，没有真实库存、运费、税费、账户或支付服务。购物车只在当前浏览器保存，不能跨设备同步。
- 构建时 React Router 的 `use client` 指令会产生 Vite 提示，但构建成功；尚未发现由此造成的页面故障。

## 主要取舍

1. **本地商品数据代替后端接口**：让客户演示不依赖服务器与网络；无法反映实时价格和库存。
2. **原创 SVG 插画代替商品照片**：避免外部图片授权和加载问题；视觉效果不等同于真实商品图。
3. **`localStorage` 代替账户购物车**：实现简单、刷新可恢复；无法跨设备同步，也不能作为正式订单数据。
4. **只做到购物车，不做结账**：优先完成从发现商品到加入购物车的闭环；付款、税费和配送需要明确业务规则后另行设计。
5. **保留响应式布局，继续验收宽屏与键盘**：初版已能在手机宽度浏览；更完整的兼容性结论需补测后才能给出。

## 启动与配置

需要 Node.js 20.19+（20 系列）或 22.12+。在源码根目录执行：

```bash
npm ci
npm run dev
```

开发地址通常为 `http://localhost:5173/`。生产构建与本地预览：

```bash
npm run build
npm run preview
```

当前不需要 `.env` 文件、API 密钥或其他私有配置。`package.json` 和 `package-lock.json` 是依赖声明；`index.html`、`tsconfig.json` 为必要配置。
