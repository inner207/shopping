# Northstar Shop

面向海外消费者的商品选购 Web 演示应用。用户可以在电脑和手机上浏览商品、搜索和筛选、查看详情，并将商品加入购物车。首版以家居与日常用品为示例，**界面使用中文，价格使用美元（USD）**。

> **项目状态：可运行的前端演示版。** 已实现商品列表、详情、购物车及本地持久化；商品和插画均为原创演示内容。没有后端、真实库存或付款流程。

## 产品目标

在有限开发时间内，优先完成可向客户演示的选购主流程：

```text
浏览商品 → 搜索或筛选 → 查看详情 → 加入购物车 → 调整数量与查看合计
```

首版使用本地演示商品数据和浏览器本地购物车，不包含账户、真实支付、订单、库存或结账承诺。

## 首版功能

| 页面 | 主要能力 |
| --- | --- |
| 商品列表 | 浏览商品，按关键词搜索、分类筛选和价格排序 |
| 商品详情 | 查看原创商品插画、名称、价格和描述，选择数量并加入购物车 |
| 购物车 | 修改数量、移除商品、查看商品金额合计，刷新后恢复 |

页面采用响应式布局，提供无搜索结果、购物车为空和无效商品链接等状态。商品插画由项目内 SVG 组件直接绘制，不依赖远程图片。

## 技术实现

- React + TypeScript + Vite：前端应用。
- React Router：列表、详情、购物车页面路由。
- CSS Modules：组件样式与响应式布局。
- 本地商品数据 + `localStorage`：无后端演示与购物车持久化。

项目从空目录搭建，没有使用现成的网站或商城模板。商品目录位于 `src/data/products.ts`；购物车状态位于 `src/features/cart/CartContext.tsx`。

## 本地运行

需要 Node.js 20.19+（20 系列）或 22.12+。在项目根目录执行：

```bash
npm install
npm run dev
```

开发服务器默认打开 `http://localhost:5173/`。生产构建与本地预览：

```bash
npm run build
npm run preview
```

本次已完成依赖安装和生产构建，并在本地浏览器验证了中文搜索、空结果、加购、金额计算和刷新恢复。当前演示地址为 `http://127.0.0.1:4173/`，仅在本机预览服务运行期间有效。

## 已知边界

- 商品信息、美元价格及插画均是演示数据，不代表真实在售商品。
- 购物车只保存在当前浏览器，无法跨设备同步；暂不支持结账。
- 宽屏和完整键盘验收仍需按 [任务拆分](./docs/task-breakdown.md) 中的清单继续检查。

- **不得使用现成的网站模板、商城模板或已有项目成品**。可以以使用官方脚手架初始化空项目。
- 商品数据为模拟内容，无后端、登录或真实支付。
